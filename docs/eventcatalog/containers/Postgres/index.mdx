## Overview

Each domain owns its own tables.

| Table | Domain |
|---|---|
| `users` | identity |
| `attempts`, `attempt_tasks` | attempt |
| `sandboxes` | sandbox |

At most one active sandbox per user:

```sql
CREATE UNIQUE INDEX one_active_sandbox_per_user
  ON sandboxes (user_id)
  WHERE state IN ('provisioning', 'ready', 'assigned');
```
