## Overview

Exam mode as it works locally today, started from the page with no CLI step. The hop-by-hop prose is
in `docs/FLOWS.md` section 6.

<NodeGraph />

## Reading the graph

1. **Start.** `POST /api/exam` takes the script lock, draws tasks by CKA domain weight (largest-remainder
   quotas), saves [exam.json](/docs/containers/ExamFile/0.0.1) and replies 202 straight away.
2. **Setup.** Every `setup.sh` runs at once, then the `order: last` tasks run one by one. The page polls and
   shows "N of M tasks set up". Practice check and solution answer 409 while the exam runs.
3. **Clock.** Only when every task is set up does the deadline start, so setup time is not exam time. The
   script lock is released.
4. **Work.** The candidate uses the terminal and `ssh`es to each task's node. Flags are saved as they change.
   If the server restarts, it reloads the exam with the same deadline and redoes any unfinished setup.
5. **End.** `POST /api/exam/end` runs every `check.sh` at once. Each task counts by its weight and 66% passes.
6. **Back.** `DELETE /api/exam` removes the file and practice mode returns.

The hosted plan for the same journey is [Quiz Attempt Lifecycle](/docs/flows/QuizAttemptLifecycle/0.0.1).
